RAMchecker can check various data about the current service memory.

/rc Shows current ,memory usage details (max, allocated, used, free, available) and 1/5/15 minute average TPS
/rc autocheck on ,Turns on automatic memory monitoring (if currently off)
/rc autocheck off ,Turns off automatic memory monitoring (stops background checking)
/rc autocheck status ,Checks whether automatic monitoring is currently enabled
/rc update check (support on Beta)
